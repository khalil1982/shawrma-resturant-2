## 🔑 المعلومات الأساسية

### المنصة والتقنية
- **Platform:** Electron Desktop Application
- **Frontend:** HTML / CSS / JavaScript
- **Backend:** Node.js (Local)
- **Database:** SQLite (Offline-First)
- **Mobile (Future):** Flutter

### العملة والمعايير
- **العملة:** الشيكل الإسرائيلي (₪ / ILS)
- **التنسيق:** ₪123.45 (منزلتان عشريتان)

### المستخدمون
- **Admin:** صاحب المطعم (صلاحيات كاملة)
- **Cashier:** الكاشير (صلاحيات محدودة)

## 📊 معايير القبول العامة

✅ **يجب تسجيل الدخول قبل الوصول لأي وظيفة في النظام**  
✅ **وجود زر خروج واضح في جميع الشاشات**  
✅ لا يمكن إغلاق وردية بوجود فرق دون سبب  
✅ لا يمكن تعديل الإعدادات إلا من Admin  
✅ جميع العمليات تحفظ محليًا فورًا  
✅ تجربة استخدام سريعة وواضحة للكاشير  
✅ عرض جميع المبالغ المالية بالشيكل (₪) مع منزلتين عشريتين  
✅ لا يمكن إنشاء طلب دون تحديد نوعه (طاولة / سريع / خارجي)  
✅ لا يمكن استخدام طاولة مشغولة لطلب جديد  
✅ يجب إغلاق طلب الطاولة قبل إتاحتها للاستخدام مرة أخرى
