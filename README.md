# 🥙 نظام إدارة مطعم شاورما - Shawrma Restaurant POS

نظام نقطة بيع (POS) offline-first مبني بتقنية Electron لإدارة مطعم شاورما بشكل كامل.

---

## 📋 نظرة عامة

نظام متكامل لإدارة جميع عمليات المطعم من المبيعات والورديات إلى التقارير المالية والمخزون، مع التركيز على العمل offline-first وسهولة الاستخدام.

### ✨ المميزات الرئيسية

- ✅ **Offline-First**: يعمل بالكامل بدون إنترنت
- ✅ **دعم RTL كامل**: واجهة عربية بالكامل من اليمين لليسار
- ✅ **نظام صلاحيات**: Admin / Manager / Cashier
- ✅ **إدارة الورديات**: صباحية ومسائية مع رقابة مالية
- ✅ **نقطة بيع سريعة**: واجهة بسيطة وسريعة للطلبات
- ✅ **تقارير مفصلة**: يومية وفترة ووردية
- ✅ **إدارة المصاريف**: تتبع كامل للمصروفات
- ✅ **Audit Log**: تسجيل كل العمليات الحساسة

## 🗄️ قاعدة البيانات (SQLite)

### الجداول الأساسية

#### 1. المستخدمون والصلاحيات
- `roles` - الأدوار (Admin, Manager, Cashier)
- `permissions` - الصلاحيات
- `role_permissions` - ربط الأدوار بالصلاحيات
- `users` - المستخدمون
- `sessions` - الجلسات النشطة

#### 2. الورديات
- `shifts` - الورديات
- `cash_variance_details` - تفاصيل الفروقات المالية
- `cash_movements` - حركات النقد

#### 3. القوائم والأصناف
- `categories` - فئات الأطعمة
- `menu_items` - أصناف القائمة
- `menu_item_options` - خيارات الأصناف

#### 4. الطلبات
- `orders` - الطلبات
- `order_items` - أصناف الطلبات
- `order_item_options` - خيارات أصناف الطلبات
- `order_status_history` - تاريخ حالات الطلب

#### 5. المصاريف
- `expenses` - المصروفات

#### 6. النظام
- `audit_logs` - سجلات التدقيق
- `settings` - الإعدادات
- `backups` - النسخ الاحتياطية

## 🚀 البدء السريع

### المتطلبات

- **Node.js**: v16 أو أحدث
- **npm**: v7 أو أحدث
- **نظام التشغيل**: Windows / macOS / Linux

### التثبيت

```bash
# 1. استنساخ المشروع
git clone <repository-url>
cd shawrma-restaurant-pos

# 2. تثبيت المكتبات
npm install

# 3. إعادة بناء sqlite3 لـ Electron
npm run rebuild

# 4. تشغيل التطبيق
npm start
```

### التطوير

```bash
# تشغيل في وضع التطوير
npm run dev

# بناء التطبيق
npm run build
```

## 💰 التدفق المالي

### 1. فتح الوردية
```
المدير → فتح وردية → إدخال رصيد الافتتاح → الوردية نشطة
```

### 2. المبيعات
```
الكاشير → إنشاء طلب → إضافة أصناف → الحساب التلقائي → تأكيد
↓
الطلب يُربط بالوردية تلقائياً
```

### 3. إغلاق الوردية
```
المدير → حساب النقد الفعلي → إدخال الرصيد الفعلي
↓
النظام يحسب: الرصيد المتوقع = افتتاح + مبيعات
↓
الفرق = الفعلي - المتوقع
↓
إذا يوجد فرق → إلزام بإدخال السبب → إغلاق
```
