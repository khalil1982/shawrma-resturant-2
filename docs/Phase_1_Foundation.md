# Phase 1 – Foundation & Architecture Setup

## الهدف
إنشاء الأساس التقني لتطبيق Electron مع ضمان Offline-First وقابلية التوسّع المستقبلية.

## النطاق
- إعداد مشروع Electron
- هيكلة المشروع (UI / Logic / Data)
- إعداد SQLite
- نظام الصلاحيات
- دعم RTL واللغة العربية

## المخرجات
- تطبيق Desktop أساسي يعمل
- قاعدة بيانات محلية
- بنية جاهزة للتوسّع
